# Instalación de Trail

Para instalar y correr el proyecto **Trail**, sigue estos pasos:

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/prxska/lisan2.git
   cd lisanv2
   npm install
   npm list --depth=0
   ng serve
    # o si usas Ionic:
    ionic serve
